## 📌 Core iOS & Swift Interview Topics

### 1. **Swift Language**

* Value types vs Reference types (struct vs class vs enum)
* ARC (Automatic Reference Counting) – strong, weak, unowned
* Protocols, Extensions, Generics
* Error Handling (`try`, `throw`, `catch`)
* Closures, Escaping vs Non-Escaping
* Property wrappers (`@State`, `@Published`, `@ObservedObject` if SwiftUI)
* Concurrency (GCD, async/await, DispatchQueue, OperationQueue)

### 2. **iOS Fundamentals**

* App lifecycle (UIKit & SwiftUI differences)
* ViewController lifecycle
* Storyboard vs Programmatic UI vs SwiftUI
* Target-Action, Delegates, Notifications, KVO
* AutoLayout & Constraints
* App states (active, background, suspended)

### 3. **Memory & Performance**

* Strong reference cycles & memory leaks
* Instruments usage (Leaks, Time Profiler)
* Lazy loading & caching
* Optimizing scrolling performance (UITableView / UICollectionView)

### 4. **Networking**

* URLSession – GET/POST request flow
* Codable for JSON Parsing
* Combine / async-await with networking
* Error handling in API calls
* Offline storage strategies

### 5. **Data Persistence**

* CoreData basics (entities, relationships, context)
* UserDefaults vs Keychain vs FileManager
* SQLite / Realm (bonus if asked)

### 6. **Architecture & Patterns**

* MVC, MVVM, VIPER basics
* Dependency Injection
* SOLID principles in iOS
* Coordinator Pattern

### 7. **System & Advanced iOS**

* Push Notifications & Notification Service Extension (NSE)
* App Groups, Extensions (Widget, Siri, etc.)
* Background tasks (fetch, processing, URLSession background)
* Keychain security basics
* Deep Linking (Universal Links, Custom URL Schemes)

### 8. **Practical Coding Questions**

* Reverse a string / palindrome check in Swift
* Remove duplicates from array
* Find first non-repeating character in a string
* Sorting algorithms in Swift (bubble, selection, quicksort)
* LRU cache / Linked List basics
